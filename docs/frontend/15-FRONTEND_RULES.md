# Frontend Rules

## 1. Purpose

This document defines the engineering rules for the HiRotoli frontend.

These rules exist to keep the frontend:

- Consistent
- Maintainable
- Predictable
- Accessible
- Performant
- Secure
- Easy to debug
- Easy to extend

Every frontend change should follow these rules unless there is a documented reason not to.
