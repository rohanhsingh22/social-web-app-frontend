# Design System

## 1. Purpose

This document defines the shared visual foundation of HiRotoli.

The design system exists to ensure that the application feels like one product rather than a collection of unrelated screens.

It defines:

- Design principles
- Color usage
- Typography
- Spacing
- Borders
- Radius
- Shadows
- Icons
- Components
- Interaction patterns
- Toli identity usage
- Light and dark themes

---

# 2. Design Philosophy

HiRotoli should feel:

- Human
- Modern
- Friendly
- Social
- Calm
- Expressive
- Approachable

The interface should prioritize people and conversations over visual decoration.
